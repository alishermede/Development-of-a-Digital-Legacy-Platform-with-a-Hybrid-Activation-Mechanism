# Crypto Core

Client-side cryptography used in the owner's browser and in the Telegram Mini App: AES-256-GCM, Argon2id + HKDF (encryption and authentication keys), X25519 sealed boxes, Shamir's Secret Sharing for *k* ≥ 2, safety codes.

Requirements: FR-CRY-01…12, NFR-SEC-01, NFR-SEC-02. Responsible: Alisher Medebaev.
