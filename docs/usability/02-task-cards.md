# Карточки заданий для участников (Task Cards)

Инструкция для наблюдателя: зачитайте участнику текст ситуации ровно так, как он написан. Не подсказывайте интерфейсные решения и кнопки. Подсказку можно дать только после 90 секунд полного затруднения (зафиксировать как "успех с подсказкой").

---

### T1: Регистрация
* **Ситуация для участника:** «Вы решили попробовать сервис безопасной передачи данных "Capsula". Создайте новый аккаунт и сохраните ключ восстановления».
* **Целевой сценарий:** S1

### T2: Первая капсула и доверенные лица
* **Ситуация для участника:** «Оставьте семейные документы и инструкции для своей дочери, а также выберите двух людей, которые будут подтверждать событие, если что-то случится».
* **Целевой сценарий:** S2, S3, S4

### T3: Настройка проверки
* **Ситуация для участника:** «Настройте сервис так, чтобы он проверял, всё ли у вас в порядке, каждые 2 недели (14 дней) в 18:00».
* **Целевой сценарий:** S4

### T4: Ответ на проверку
* **Ситуация для участника:** «Вам поступил запрос "Вы в порядке?". Ответьте на него (сначала в Telegram, затем через SMS-ссылку)».
* **Целевой сценарий:** S5

### T5: Проверка статуса
* **Ситуация для участника:** «Проверьте в кабинете, принял ли приглашение кто-то из людей, которых вы добавили».
* **Целевой сценарий:** S3-5, S4-5

### T6: Принятие приглашения
* **Ситуация для участника:** «Ваш знакомый попросил вас стать его доверенным лицом в сервисе. Примите это приглашение».
* **Целевой сценарий:** S6

### T7: Подтверждение события
* **Ситуация для участника:** «Вы узнали, что ваш знакомый перестал выходить на связь и отвечать на проверки. Подтвердите событие в системе».
* **Целевой сценарий:** S7

### T8: Отмена и открытие
* **Ситуация для участника:** 
  * *Для владельца:* «Вы вернулись, и процесс передачи уже запущен. Остановите его, используя мастер-пароль».
  * *Для получателя:* «Вам передан доступ к капсуле. Откройте письмо».
* **Целевой сценарий:** S8
